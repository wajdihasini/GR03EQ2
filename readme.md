## Lancer un TD

Exemple avec le TD1 d'Intégration Web :

```bash
cd td1
npm install
npm start
```

L'application s'ouvre sur http://localhost:3000.

> `node_modules` n'est pas versionné : `npm install` est nécessaire après un `git clone`.
